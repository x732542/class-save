物件 = 屬性(特徵) + 方法(會動的)

Q: 如何取得物件的屬性?
    物件.屬性
    . ==>的

Q: 如何取得物件的方法?
    物件.方法()
    物件.方法(資料)

Q: 變數的命名規則?
    1.大小寫英文|底線|數字
    2.不能數字開頭，不能用減號(-)
    3.避開保留字、關鍵字，若無法區分則在前面加上"my"
    ##不數字開頭 不用保留字

Q: 如何宣告變數?
    var 變數名稱;
    let 變數名稱;
    const 變數名稱  = 值;

Q: 什麼時候需要用到變數?
    有一個東西等一下才會用到的時候
    ##需要放東西的時候

    function 函式名稱(參數){

    }
    
    ##var = string()

   函式名稱();

Q: if 判斷式的結構?
    if(條件|比較){

Q: 如何宣告一個陣列?

    var 變數 = [];
    var apple = [];

    ##var x = [1,2,300;]
Q: 如何取得陣列內的資料?
    變數[索引]
    apple[0]

##  console.log(x[1])
Q: 如何放資料到陣列?
    變數[索引] = 資料
    apple[0] = "蘋果"

    ##x[0] = 123
Q: 什麼時候需要用到陣列?
    需要很多變數紀錄資料，且資料具有相同的型別、相同的意義
    EX:記錄全班同學的姓名
    ##需要存放大量相同屬性 有關係的資料

Q: 如何宣告一個物件?

    var 變數 = { 屬性: 值 }
    var apple = { price: 100 }

    ##var{a:b}

Q: 如何取得物件內的屬性?

    變數.屬性   
    變數["屬性"]

    ##log(x)

Q: 如何新增屬性?
    變數.新的屬性 = 值
    變數["新的屬性"] = 值

Q: 什麼時候需要用到物件?
    需要很多變數紀錄資料，且這些資料都在描述同一事物時
